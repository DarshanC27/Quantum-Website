Important: No website can silence other apps on iPhone — only iOS Focus can do that. Follow this one-time setup (about 2 minutes), then notifications from every app will be blocked while you study.

Part 1 — Create a Study Focus that blocks everything

Part 2 — Turn it on when you study

Part 3 — Auto-enable when you open this app (optional)

  1. Open the Shortcuts app → Automation tab → +
  2. Choose App → Is Opened → select Focus (your home screen icon)
  3. Add action Set Focus → Study → Turn On
  4. Turn off Ask Before Running → tap Done
